## House-pattern cheat-sheet (READ THIS ONCE, don't re-discover it)

**Repo:** `gqsa-Site` (this workspace). Node + Express 4 + `node:sqlite` (`DatabaseSync`,
**synchronous** API). EJS for public pages; `/admin` is the React SPA (`admin-frontend/`).

**Admin gate (every new route uses this verbatim):**
```js
function isAdmin(req) {
  return !!process.env.ADMIN_USERNAME && req.session.username === process.env.ADMIN_USERNAME;
}
// first line of every admin route:
if (!isAdmin(req)) return res.status(403).json({ error: 'Not admin' });
```
`isAdmin` is defined once, just above the `/admin` routes (grep `function isAdmin(req)`).

**CSRF posture (A1):** a global middleware checks **POST only**. It accepts the token from the
`csrf` body field **or** the `X-CSRF-Token` header. `/paypal-webhook` is exempt (server-to-server).
- For **JSON** POSTs: send the header (the React SPA already does).
- For **multipart uploads**: `express.urlencoded` does NOT parse multipart, so `req.body?.csrf` is
  empty → **the token MUST come from the `X-CSRF-Token` header.** That already works (the middleware
  checks the header). Do not try to put `csrf` inside the multipart body.
- **GET routes are CSRF-exempt** (read-only) — that's why `/api/admin/roadmap` and
  `/api/admin/boot` don't carry a token.

**JSON body parsing — the house pattern (IMPORTANT):**
`express.json()` is **NOT registered** in this app. The existing JSON POST routes
(`POST /admin/toggle-roadmap`, `POST /admin/notify`) parse the body **manually**:
```js
let body = '';
req.on('data', chunk => { body += chunk; });
req.on('end', () => {
  try { const { x } = JSON.parse(body); ... }
  catch (e) { res.status(400).json({ error: e.message }); }
});
```
**Do NOT add a global `app.use(express.json())`** — it would consume `req`'s body stream *before*
those two manual parsers run and silently break them (they'd read an empty body). Reuse the manual
pattern (or a tiny shared `readJsonBody(req)` helper — see Step 3) for all new JSON routes.
(`express.raw` is only used, deliberately, on `/paypal-webhook` for signature-exact bytes.)

**Static serving:** `app.use(express.static('public'))` is registered near the top. So anything
written under `public/…` is automatically served at `http://host/…`. Uploaded files under
`public/uploads/…` are therefore reachable at `/uploads/…` with **no extra route** — this matches
the B1 seed paths (`/uploads/comics/<id>/<n>.png`).

**DB:** `const db = new DatabaseSync('database.db')` (synchronous). Content tables (grep
`CREATE TABLE IF NOT EXISTS comics`): `tiers`, `stories`, `comics`, `comic_pages`, `images`,
`videos`. Parent/child: `comics` → `comic_pages` with `ON DELETE CASCADE` +
`UNIQUE(comic_id, page_number)`. Current columns:
- `comic_pages`: id, comic_id, page_number, file_path — **no `caption` yet** (Step 2 adds it).
- `images`: has `caption` already.
- `videos`: has `description`, **no `caption`** (Step 2 adds it).

**Idempotent column add (node:sqlite has no `ADD COLUMN IF NOT EXISTS`):**
```js
const cols = db.prepare('PRAGMA table_info(comic_pages)').all().map(r => r.name);
if (!cols.includes('caption')) db.exec('ALTER TABLE comic_pages ADD COLUMN caption TEXT');
```
Run this at boot, right after the content-table `db.exec(...)` (grep the `videos (` table end).
It's a no-op on restarts that already have the column → idempotent.

**Test harness house style (copy from `test-a3-accounts.mjs`):**
- **Self-contained** `.mjs`; spawns its OWN server on a **free port** with a controlled env
  (known `ADMIN_USERNAME`, `SESSION_SECRET`, raise `LOGIN_MAX_ATTEMPTS` if you log in a lot).
- `spawn(process.execPath, ['server.js'], { cwd, env, stdio: 'inherit' })` — **`stdio: 'inherit'`
  is mandatory**: the DSH sandbox denies piped child stdio with EPERM; `pipe` fails, `inherit` works.
- Every `fetch` uses `{ headers: { connection: 'close' } }` — Windows + abrupt exit + a live
  keep-alive socket trips a libuv assertion that clobbers the exit code.
- `freePort()` via `net.createServer().listen(0)`, then `waitReady()` polling `GET /`.
- `check(name, ok)` helper counting `PASS/FAIL`; throwaways use **ts-suffixed** usernames/ids so
  they never collide with the shared `database.db`.
- **Re-run the A1/A2/A3 suites** after touching shared code to prove no regression:
  `node test-a1-security.mjs` · `node test-a2-subscriptions.mjs` · `node test-a3-accounts.mjs`.

**Sandbox / env gotchas already paid for (don't re-troubleshoot):**
- **multer is pure JS** (no native `postinstall`) → `npm install multer` works under the DSH
  sandbox, unlike `bcrypt` (which needed the `bcryptjs` swap). Use plain `multer`.
- A **ghost `node server.js`** can squat on :3000 from a previous session and make a fresh server
  die with EADDRINUSE (or 404 new routes). **Verify the server's identity before a smoke test** by
  hitting a route only the NEW code has (expect the new 403/200, not a 404). Kill stray node procs
  (`Get-Process node`) or just use a free port (the harness already does).
- `public/uploads/` is an **upload artifact**: per C3 the Render free-tier disk is wiped on every
  restart, and we re-upload test content each time. It should be **gitignored** (binary content,
  regenerable) — Step 1 adds the `.gitignore` line.

### Step 1 — multer + `POST /api/admin/upload`  ⬜
**Goal:** the upload route the editors will call. Multer installed; one admin-gated, CSRF-protected
multipart endpoint that saves a file under `public/uploads/{kind}/{uuid}/` and returns the
`file_path` to store in the DB.

**Touch:** `package.json` (+`node_modules`), `server.js` (one new route + a tiny helper), `.gitignore`.

**Do:**
1. `npm install multer` (pure JS — safe under the sandbox).
2. In `server.js`, near the other imports: `import multer from 'multer'; import { mkdirSync } from 'node:fs'; import { randomUUID } from 'node:crypto';`
3. Build the uploader **once** (abstract the location — C3/O3: the whole thing is one function we
   can later swap for object storage):
   ```js
   // B2.4: uploads land under public/uploads/{kind}/{uuid}/ — served for free by the
   // existing express.static('public'). The DB stores the URL-style path /uploads/{kind}/{uuid}/{name}.
   const uploadRoot = path.join(__dirname, 'public', 'uploads');
   const uploader = multer({
     storage: multer.diskStorage({
       destination: (req, file, cb) => {
         const kind = ['comics','images','videos'].includes(req.body?.kind) ? req.body.kind : 'misc';
         const dir = path.join(uploadRoot, kind, randomUUID());
         mkdirSync(dir, { recursive: true });
         cb(null, dir);
       },
       filename: (req, file, cb) => cb(null, file.originalname.replace(/[/\\]/g, '_')),
     }),
     limits: { fileSize: 100 * 1024 * 1024 }, // 100 MB
   });
   ```
4. Register **one** route (after `POST /admin/notify`, before the admin-SPA static mount):
   ```js
   // B2.4: multipart upload. CSRF token arrives via the X-CSRF-Token header (urlencoded does not
   // parse multipart, so req.body.csrf is empty here — the global middleware already checks the header).
   app.post('/api/admin/upload', (req, res) => {
     if (!isAdmin(req)) return res.status(403).json({ error: 'Not admin' });
     uploader.single('file')(req, res, (err) => {
       if (err) return res.status(400).json({ error: err.message });
       const f = req.file;
       if (!f) return res.status(400).json({ error: 'No file field "file" in the multipart body' });
       const urlPath = '/' + f.path.split(path.sep).slice(-5).join('/'); // /uploads/{kind}/{uuid}/{name}
       res.json({ success: true, file_path: urlPath, originalName: f.originalname, bytes: f.size });
     });
   });
   ```
   (Deriving `urlPath` from `f.path` keeps it correct even if the root moves — that's the
   "abstract the location" part.)
5. `.gitignore`: add `public/uploads/` (upload artifact; wiped + re-uploaded per C3).

**Verify (green = done):** a throwaway node script (or `curl` against a manually-started server)
that: (a) as **admin** with the `X-CSRF-Token` header, POSTs a small temp file with
`kind=comics` + `file=@…` → 200 `{file_path:"/uploads/comics/<uuid>/…"}` and the file exists on disk
and is `GET`-able at that URL; (b) as a **non-admin** → 403; (c) as admin **without** the CSRF
header → 403. Clean up the temp file.
**Gotchas to note:** how `kind` is read from the multipart body; the 403/400 shapes.
**Status:** ✅ (2026‑09‑24)
**Done / gotchas (fill in):** Built: `multer` (pure JS) in `package.json`; `randomUUID` + `mkdirSync` added to the existing crypto/fs imports; `publicRoot`/`uploadRoot` consts + the `uploader` (diskStorage → `public/uploads/{kind}/{uuid}/`, 100 MB limit) + `POST /api/admin/upload` (admin-gated, CSRF via `X-CSRF-Token` header) inserted between `/admin/notify` and the B2.2 SPA static mount; `.gitignore` gained `public/uploads/`. // B2.4: the editors need per-page and per-video captions. ADD COLUMN has no IF NOT EXISTS,

### Step 3 — `GET /api/admin/content` (list) + shared `readJsonBody` helper  ⬜
**Goal:** the read-only list endpoint the editors fetch to render existing content, **plus** a small
shared helper for manual JSON parsing so Steps 4–6 don't each re-write it.

**Touch:** `server.js` only.

**Do:**
1. A tiny helper near the admin routes (reuse everywhere in Steps 4–6):
   ```js
   // B2.4: manual JSON body parse (the house pattern — express.json is deliberately NOT registered,
   // see the /admin/toggle-roadmap + /admin/notify comments). Returns a Promise<object>.
   function readJsonBody(req) {
     return new Promise((resolve, reject) => {
       let body = '';
       req.on('data', c => { body += c; });
       req.on('end', () => { try { resolve(body ? JSON.parse(body) : {}); } catch (e) { reject(e); } });
       req.on('error', reject);
     });
   }
   ```
2. The list endpoint (after the helper; admin-gated; GET → CSRF-exempt):
   ```js
   // B2.4: the editors' data source — every content row + counts, in one read.
   app.get('/api/admin/content', (req, res) => {
     if (!isAdmin(req)) return res.status(403).json({ error: 'Not admin' });
     const stories = db.prepare('SELECT * FROM stories ORDER BY id').all();
     const comics = db.prepare('SELECT * FROM comics ORDER BY id').all();
     const pages  = db.prepare('SELECT * FROM comic_pages ORDER BY comic_id, page_number').all();
     const images = db.prepare('SELECT * FROM images ORDER BY id').all();
     const videos = db.prepare('SELECT * FROM videos ORDER BY id').all();
     res.json({
       stories, comics, pages, images, videos,
       counts: { stories: stories.length, comics: comics.length,
                 pages: pages.length, images: images.length, videos: videos.length },
     });
   });
   ```

**Verify (green = done):** as **admin**, `GET /api/admin/content` → 200 with all five arrays and
`counts` matching the B1 seed (2 stories, 2 comics, 5 pages, 1 image, 1 video); as **non-admin** → 403.
**Gotchas to note:** exact response shape (the editors will code against it).

### Step 4 — stories CRUD  ⬜
**Goal:** create / update / delete a story. (Single text entity — the simplest CRUD.)

**Touch:** `server.js` only (three routes after Step 3's route).

**Do** (all admin-gated + `readJsonBody`; set `updated_at` on writes; `publish_date` = epoch ms):
```js
app.post('/api/admin/stories', async (req, res) => {
  if (!isAdmin(req)) return res.status(403).json({ error: 'Not admin' });
  try {
    const { title, description, body, publish_date, is_member, tier_id } = await readJsonBody(req);
    if (!title || !body) return res.status(400).json({ error: 'title + body required' });
    const now = Date.now();
    const r = db.prepare('INSERT INTO stories (title, description, body, publish_date, is_member, tier_id, created_at, updated_at) VALUES (?,?,?,?,?,?,?,?)')
      .run(String(title), description ?? null, String(body), publish_date ?? now, is_member ? 1 : 0, tier_id ?? null, now, now);
    res.status(201).json({ success: true, id: Number(r.lastInsertRowid) });
  } catch (e) { res.status(400).json({ error: e.message }); }
});

app.put('/api/admin/stories/:id', async (req, res) => {
  if (!isAdmin(req)) return res.status(403).json({ error: 'Not admin' });
  const id = Number(req.params.id);
  const row = db.prepare('SELECT * FROM stories WHERE id = ?').get(id);
  if (!row) return res.status(404).json({ error: 'Not found' });
  try {
    const b = await readJsonBody(req);
    db.prepare('UPDATE stories SET title=?, description=?, body=?, publish_date=?, is_member=?, tier_id=?, updated_at=? WHERE id=?')
      .run(b.title ?? row.title, b.description ?? row.description, b.body ?? row.body,
           b.publish_date ?? row.publish_date, (b.is_member ?? row.is_member) ? 1 : 0,
           b.tier_id === undefined ? row.tier_id : b.tier_id, Date.now(), id);
    res.json({ success: true, id });
  } catch (e) { res.status(400).json({ error: e.message }); }
});

app.delete('/api/admin/stories/:id', (req, res) => {
  if (!isAdmin(req)) return res.status(403).json({ error: 'Not admin' });
  const r = db.prepare('DELETE FROM stories WHERE id = ?').run(Number(req.params.id));
  if (r.changes === 0) return res.status(404).json({ error: 'Not found' });
  res.json({ success: true });
});
```
**Note:** `DELETE` is exempt from the POST-only CSRF middleware (it checks `method !== 'POST'`).
That's acceptable here — the route is still `isAdmin`-gated and the SPA is same-origin. If you want
CSRF on DELETE too, add `if (req.method === 'DELETE' && !csrfOk) ...` — but **don't** change the
global middleware's `method !== 'POST'` line (other code depends on it).
**Verify (green = done):** as admin: POST a story (201 + id) → it appears in `GET /api/admin/content`;
PUT to change title/body → change persisted; DELETE → gone; non-admin → 403 on all three.
**Gotchas to note:** the DELETE-vs-CSRF note above.
**Status:** ✅ (2026‑09‑24)
**Done / gotchas (fill in):** Built (in `server.js`, after Step 3's list route and before the B2.2 SPA static mount): the three stories routes exactly per spec — `POST /api/admin/stories` (201 `{success, id}`; 400 `title + body required`; `publish_date` = epoch ms, defaults to now), `PUT /api/admin/stories/:id` (404 on missing id; sets `updated_at`), `DELETE /api/admin/stories/:id` (404 when 0 rows).
